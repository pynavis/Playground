pyNavis Playground 0.1.0

Experimental tools for pyNavis

Playground is a second extension for pyNavis, the open-source pyRevit-style add-in for Autodesk Navisworks. Nothing here is a finished pyNavis tool. Every tool carries an honest status, and most have never run inside Navisworks. Install the ones you need, try them on a real model, and tell us what happened.

140 tools: 100 untested, 40 launched, 0 verified, 0 known issue.

The public user ask behind a tool is quoted word for word for 5 tools; 40 tools have only leads, threads a person still has to read; 95 tools have no public source on record.

Status ladder
StatusMeaning
UntestedNever executed inside Navisworks. Passed the headless checks only.
LaunchedRan inside Navisworks at least once with no error logged; nobody checked the result yet.
VerifiedA person confirmed it does what its tooltip says, on a real model.
Known issueRan and misbehaved. The note says how. Still installable.

A status only goes up with evidence: a log excerpt, a pynavis run transcript, or a named person's check.

Install

You need pyNavis 1.3.0 or later.

The whole extension. Download Playground.extension.zip, unzip it, put the Playground.extension folder in %APPDATA%\pyNavis\extensions\, and click pyNavis > Reload. To remove it, delete the folder and Reload.

Only the tools you want. In Navisworks, click pyNavis > Playground. It opens a browser over the same catalog: search, read the user ask behind each tool, tick the ones you want, and click Install. It downloads only those tools, plus the shared library they all use, and reloads.

Every installed Playground tool is marked experimental on the ribbon. Tried one? Report back, whether it worked or not.

Model

Select

  • Select SimilarUntestedLeadsSelects every item that shares the property values you tick with the first selected item, in the whole model, its own model or the selection.
  • Filter SelectionUntestedKeeps or removes the selected items whose property passes a test (equals, contains, greater than, is missing...) without running a new search.
  • InvertLaunchedLeadsSelects everything the current selection leaves out, leaving hidden items out. With nothing selected it selects everything visible. Shift+Click for settings.
  • Select by FileUntestedSelects every item of the appended files you tick, remembering your last choice. Shift+Click for settings.
  • Save as SetLaunchedSaves the current selection as a selection set named from a template such as Ducts - 412 items - 2026-10-05, in the Playground folder. Shift+Click for settings.
  • BackUntestedRestores the selection you had before this one, like Back in a browser. After clearing the selection it brings the last one back.
  • ForwardUntestedRestores the next selection after going Back.
  • HistoryUntestedLists the selections made in this model (time, item count, main category) and restores the one you choose. Shift+Click for settings.
  • Pick OrderLaunchedRecords the items you click, in the order you click them, so you can select, number, export or color them in that order. Click it, then click items one at a time (Ctrl+click works too); the bar along the bottom of the window counts them.
  • Select PickedUntestedSelects the items in the pick list.
  • Number PickedUntestedWrites Playground > Sequence = 1, 2, 3... onto the picked items in pick order, keeping their other Playground properties. One undo step.
  • Export PickedUntestedWrites the pick list to Excel or CSV: order, name, category, Element ID, GUID, source file and centre point in model units.
  • Color PickedUntestedColors the picked items from light to strong blue along the pick order. One undo step.
  • Clear PickedUntestedEmpties the pick list of this model.

Find

  • Quick FindUntestedFinds any element by name, Element ID, category, type, mark or level as you type. Enter selects and zooms, Shift+Enter selects every match. Shift+Click for settings.
  • Search Set WizardUntestedBuilds a search set step by step: where to search, conditions picked from the model's own properties and values, a live count, then name and folder.
  • Batch SetsUntestedCreates one search set per value of a property, such as one set per level, named and foldered from templates. One undo step.
  • Sets LibraryUntestedLeadsPublishes search sets to a shared library and imports them into other models, or renames and deletes libraries.
  • Export SetsUntestedLeadsWrites the sets you choose to a Playground XML file: search sets as conditions, selection sets as item references that survive into other files.
  • Import SetsUntestedLeadsRecreates sets and folders from a Playground XML file, finding static set items by path, GUID or Element ID, and reports what was found.
  • Repair Search InUntestedLeadsFinds search sets whose Search In scope is empty or points at models that are gone, and re-scopes them to matching models or the whole model.

Inspect

  • What Is ItLaunchedEverything Navisworks knows about one item in one card: identity, Revit IDs, source file and tree path, size and position, geometry, colour and state, and every property tab. Select the item first, or click it in the view when nothing is selected. A plain-text summary goes to the clipboard.
  • Properties PlusUntestedA window that follows the selection: pinned properties compared across every selected item (one value, or how many differ), and all of the first item's properties. Copy a value or select every item in the model that shares it.
  • Selection HUDUntestedShows a small readout in the bottom-left corner of the Navisworks window: how many items and objects are selected, from which models, the top categories, and a summed property when you set one. Shift+Click for settings.
  • Copy IDsLaunchedCopies one row per selected element (name, Element ID, UniqueId, IFC GlobalId, InstanceGuid, source file, tree path) as tab-separated text with a header, ready to paste into Excel. Shift+Click for settings.
  • Open in ExplorerLaunchedLeadsShows the selected item's model file in Windows Explorer: the source file it was appended from, or its Navisworks cache file (asks when both exist). With nothing selected, shows this document's own file.

Data

  • Property ExplorerUntestedScans the selection, the visible items or the whole model once, then lists every category, property and value with counts in three linked, searchable lists. Select the items with a value, save it as a search set, copy the list or export the whole index to Excel.
  • Count by PropertyLaunchedCounts objects by the values of one property, or by pairs of values of two (a two-level pivot), over the selection, the visible items or the whole model. Shows a sorted table with shares and a top 20 chart, then lets you select any group. Optional Excel export.
  • Property ExporterLaunchedLeadsExports the properties you tick for the selected objects (or their geometry items) to a styled Excel workbook or a CSV file, with name, file, Element ID and GUID columns in front. Your choice is remembered and can be saved as a named template.
  • Data ValidatorUntestedChecks the model against BEP rules kept as JSON files in the team rules folder (every duct has a system name, every element a level, marks filled in, comments matching a pattern). Reports passes and failures per rule with element links, and can export to Excel and save a selection set per failing rule. Shift+Click for settings.
  • Bulk Property WriterUntestedLeadsWrites up to 10 custom properties to the selected items in one step, merged into an existing tab, or writes a spreadsheet's columns to the objects its Element ID, GUID or property column matches, with a preview of matched, unmatched and ambiguous rows first.
  • Find and ReplaceUntestedFinds text or a regular expression in property values (all properties or one) and replaces it after a preview. Native values are read-only, so corrections go to a Playground Corrected tab; values in custom tabs are edited in place.
  • Property MapperUntestedFills one standard tab (System, Level, Mark...) from whichever source property each model uses, in order of preference, with optional regex clean-up and per-model overrides. Shows coverage per field and model before writing. Profiles are team-shareable and export to JSON.
  • External Data LinkUntestedLeadsLinks a spreadsheet to this document by a key column (Element ID, GUID or a property) and writes its columns to a custom tab on the matched objects. Refresh re-reads the file and reports matched, unmatched and changed; links are saved with the document's Playground data.
  • Model Tree ExportLaunchedExports the selection tree to a chosen depth (4 by default) as an Excel workbook with a sheet per model: each node's depth, name, class, descendants, geometry items and hidden state, indented and one column per level so it filters in Excel.
  • Clear LabelsUntestedRemoves the value labels Property Labels drew in the view.
  • Property LabelsUntestedDraws a chosen property's value above each selected object in the view, on a short leader from the top of its box (up to 500 objects). Labels follow orbit and zoom; Clear Labels removes them.

Look

  • Color PresetsUntestedLeadsSaves a color scheme as a named preset the whole team can apply, then repaints the model from it in one step. Manage renames, deletes, exports and imports presets.
  • Trade GhostUntestedKeeps the trades you choose, or the selection, solid and fades every other model to a transparent grey. Click again to change the focus or clear the ghost. Shift+Click for settings.
  • Status PainterUntestedPaints items by construction status (Installed, In progress, Planned, On hold, Issue), sets the status of the selection, and shows the legend. Shift+Click for settings.
  • Legend MakerUntestedDraws the last color scheme as a print-ready PNG legend with swatches and counts, and can save a viewpoint that brings those colors back.
  • Match AppearanceLaunchedCopies the color and transparency of the first selected item to the rest of the selection. With one item selected, or none, click the objects to paint one by one and press Esc to finish.
  • Exploded ViewUntestedSpreads the selected objects or their models away from their common center as one undoable move, without touching the source files. Click again to collapse them back or spread them further.
  • Reset OverridesUntestedPuts back the model colors, transparency, hidden items, moved items or required and frozen flags you choose, all in one undo step.
  • BackgroundLaunchedSteps the view background through White, Light gradient, Dark gradient, Black and Horizon. Shift+Click picks one from the list or a custom color.
  • Presentation ModeUntestedClears the screen for a meeting by minimizing the ribbon to its tabs, closing add-in panels and maximizing the window. Click again or press Ctrl+Alt+F11 to put everything back. Shift+Click for settings.
  • Exit PresentationUntestedLeaves Presentation Mode and puts the ribbon, panels, window size and background back from anywhere.

Viewpoints

  • Viewpoints from ExcelUntestedLeadsExports saved viewpoints to an Excel workbook (folder, name, eye, target, up, lens, comment) in model units, or creates and updates viewpoints from one by folder and name.
  • Export ViewpointsUntestedLeadsExports only the saved viewpoints you tick, as a Navisworks viewpoints XML file for Import Viewpoints, or as a Playground package that keeps cameras, sections and comments for Viewpoint Sync.

  • Where Am ILaunchedOne popup with where the camera is: the saved viewpoint it is on, eye coordinates, compass heading and pitch, nearest level and grid intersection, lens, section, models and selection. Copy puts it on the clipboard.

Capture

  • Viewpoints to ImagesLaunchedLeadsSaves an image of every viewpoint you choose (PNG or JPG, 720p to 4K or a custom size, named by template) into a dated folder with an index.html contact sheet. Your view comes back afterwards.
  • Batch ImagesUntestedLeadsSaves images of saved viewpoints, clash results (by test and status) and Playground issues in one run, into Viewpoints, Clashes and Issues folders with one index.html contact sheet.
  • Batch PDFUntestedPrints the viewpoints you choose, in folder order or your own order, to one PDF handout: title page, contents, one page per view with its comments and a footer. A4, A3, Letter or Tabloid.

Navigate

  • Level SectionerLaunchedCuts the model at the level you choose: a section plane at the cut height above the floor, optionally the floors below hidden and a plan view. Levels come from the grid system or are estimated from the model. Shift+Click for settings.
  • Level UpUntestedMoves the level section to the next level up and says which level it is. Invisible on the ribbon; rebind it in the Shortcuts editor.
  • Level DownUntestedMoves the level section to the next level down and says which level it is. Invisible on the ribbon; rebind it in the Shortcuts editor.
  • Camera SyncLaunchedMirrors the camera live between two Navisworks windows on this computer, for two model versions side by side. Turn it on in both windows; the one you move leads.
  • Coordinate SpotterLaunchedLeadsClick points in the view to drop numbered markers with their coordinates, then get the table, a clipboard copy and an Excel or CSV file.   • Clear SpotsLaunchedRemoves the Coordinate Spotter markers from the view and starts the numbering again at P1.
  • Sheet OverlayLaunchedDraws a DXF plan over the model at a level, placed by offset and rotation or by two reference points, with its texts as labels. Once placed, one click shows it again; Shift+Click places another.
  • Clear SheetUntestedRemoves the DXF sheet overlay and its labels from the view.

  • Clash AssignerUntestedLeadsAssigns clash groups and ungrouped clashes to the trade that moves, keeps the ball-in-court history in the model, and shows who holds what and for how long. Shift+Click for settings.
  • Clash to ViewpointsUntestedSaves a viewpoint for each chosen clash or group, in folders by test and group, with a comment giving its status, distance, elements, grid and level.
  • Clash HeatmapUntestedColours elements by how many open clashes they have, lists the top hotspots, and can mark the densest spots in the view. Shift+Click clears the colours and markers.
  • Show in RevitUntestedSends the selected elements to Revit, where the Playground Link button for pyRevit selects and zooms to them.
  • Show from RevitUntestedSelects and zooms to the elements sent from Revit with the Playground Link button for pyRevit.

Clash Reports

  • Clash ExcelUntestedLeadsWrites a styled Excel report of the chosen clash tests: a summary in Clash Detective's colours, then one sheet per test with a thumbnail of each clash, filters and frozen headers.
  • Clash DashboardUntestedLeadsBuilds a one-page HTML dashboard of the chosen clash tests (status, where the open clashes are, who holds them and for how long, groups and every clash) and opens it in your browser.
  • Count MatrixUntestedCounts open and new clashes trade against trade (or model against model) across the chosen tests, as heat tables in the output window and an optional workbook.
  • SnapshotUntestedRecords the current results of the chosen clash tests as a snapshot that Clash Delta and Clash Trends compare with. Shift+Click to snapshot automatically on save, or to delete old snapshots.
  • Clash DeltaUntestedLeadsCompares the chosen clash tests now with a snapshot: new, fixed and still open clashes and status changes, in the output window and an optional workbook.
  • Clash TrendsUntestedLeadsCharts open and resolved clashes over the model's snapshots with a burn-down table, and can save it to Excel or CSV.
  • Per-Trade ReportsUntestedWrites one clash workbook (and an optional dashboard) per responsible trade into a folder, with an index, using Clash Assigner's who-moves list for unassigned clashes.

BCF

  • BCF ExportUntestedQuoteWrites Playground issues, or clash groups and clashes straight from Clash Detective, to a BCF 2.1 or 3.0 file with topics, comments, viewpoints in metres, IFC GUID components and snapshots, for Revit, Solibri, BIMcollab and other BCF tools.
  • BCF ImportUntestedReads a BCF 2.0, 2.1 or 3.0 file into the issue register, merging topics with the same GUID, saving their viewpoints under BCF in Saved Viewpoints and finding their components by IFC GUID or Revit Element ID.

Project

Models

  • Link NavigatorUntestedFrom the selected element to the model it comes from: its files, units, transform, freshness and size in the output window, then select, isolate, hide, open the folder, refresh, remove it or show it in Source Files.

  • COG CalculatorLaunchedLeadsWeighs the selected objects from closed-mesh volumes and material densities (or their Weight property), marks the combined centre of gravity in the view and lists every object with its weight, centroid and method. Shift+Click for densities.

Field
